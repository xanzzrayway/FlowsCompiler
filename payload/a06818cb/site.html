Hướng Dẫn Chi Tiết Build APK Từ File .ZIP

Cách 1: Sử dụng WebIntoApp (Nhanh nhất & Tự động)

  1. Sau khi bấm nút **"Tải bộ .ZIP Build APK"**, bạn nhận được file `.zip`.
  2. Mở trang web WebIntoApp.com.
  3. Chọn mục **"HTML / JS / CSS to App"** (hoặc chọn Upload File Zip).
  4. Tải file `.zip` vừa tạo lên, đặt tên App và Icon.
  5. Bấm **"Make App"**, chờ 1-2 phút rồi tải file `.apk` trực tiếp về điện thoại cài đặt!

Cách 2: Tự Build Trực Tiếp Trên Android (Spck Editor)

  1. Tải ứng dụng **Spck Editor** trên Google Play Store.
  2. Giải nén file `.zip` vừa xuất.
  3. Mở Spck Editor -> Chọn `Import Zip` hoặc mở thư mục đã giải nén.
  4. Vào mục **Build / Export Options** chọn **Export as APK**.

Cách 3: Build Native bằng Android Studio

Trong file `.zip` xuất ra đã tích hợp sẵn mã nguồn Native Android (`MainActivity.java` & `AndroidManifest.xml`):

  1. Giải nén file `.zip`.
  2. Nạp thư mục vào dự án Android Studio WebView.
  3. Nội dung web nằm ở thư mục `/assets/` hoặc `/www/index.html`.
  4. Bấm **Build > Build APK(s)** trong Android Studio.
